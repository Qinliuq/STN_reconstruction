# Note for the results draft: what changes in Tables 3 / 4 (emergent-peak test, 2026-11-22)

Table numbering as in the task: Table 3 = GPe beta gradient × PV+ placement (`results/beta_pvp_layout`), with the
per-type GABA:glutamate ratio rows (`results/gaba_ratio`; uniform drive + ratio = 1.02). If Table 4 is the ratio
table, the same notes apply to its uniform-drive row. Details: `summary.md`.

1. **"The upper-middle peak needs both the graded GPe beta drive and the PV+ gradient."** Keep, but qualify: the PV+
   gradient in these rows is configuration D's skew-normal cluster, which is much more concentrated than the measured
   *Pvalb* profile (Jeon 2022 Fig. 7H). Add: "With a PV+ placement drawn from the measured *Pvalb* profile the
   graded-drive case was not re-tested; under uniform drive the measured placement does not localize beta (0.65/0.25
   ratio 0.61 vs 0.41 with uniform PV+), while the configuration-D cluster leaves a weak hump at 0.55 (1.09)."
2. **"The PV+ cluster alone does not localize beta when the drive is uniform" (1.17; 1.02 with the ratio).**
   Strengthened: it also holds with measured receptor gradients (*Gria1*, *Gabra1*), the measured per-type ratio and the
   measured GPe→STN width and mapping. No combination of measured distributions produces the peak (best: 0.86, flat).
3. **New statement (limitation):** "The beta maximum at 0.6–0.7 does not emerge from measured distributions alone. The
   measured glutamate and GABA_A gradients (both higher ventrally) shift beta ventrally, and the measured GPe→STN
   projection (σ 0.22, centroids 0.41–0.94) broadens it. The peak in configuration D therefore depends on the imposed
   graded pallidal drive and on the concentrated PV+ placement."
4. **Motor-territory drive (condition M):** even a graded drive centred on the digitized somatomotor hyperdirect locus
   (0.63 ± 0.06) gives no dorsal peak when combined with the measured receptor gradients and GPe topography (ratios
   0.54–0.79). Any statement that a motor-territory beta source *explains* the sweet-spot location needs the
   configuration-D receptor/topography assumptions; say so if such a statement appears.
5. **Per-type ratio row (1.02 / 2.37):** unchanged. New: with measured gradients the ratio doubles shared beta (mostly
   in PV+ pairs) without localizing it.
6. **Rates:** the measured GPe→STN topography lowers STN rates by 17–25% (and GPe rates by ~10%) without
   recalibration; quote this wherever these conditions are compared with configuration D.
