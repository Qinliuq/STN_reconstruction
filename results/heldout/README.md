# Held-out validation of configuration D

Experimental targets that were never used for calibration. Each model prediction (`H<n>/prediction.json`, with git hash, configuration and spike-file hashes) was written before the comparison script read the data; the comparison scripts refuse to run without it. Input-regime parameters were fixed in `validation/heldout/priors.json` before any run. Configuration-D parameters were not changed. Code: `validation/heldout/` (see its README).

Revision 2026-11-18 (after review of the first comparison): the rat reference is the 45 distinct single units (28 of the 73 exported rows are duplicates); H1 adds a phenotype criterion (model cells assigned to the data's burst/pause centroids), because a split along another axis passed the original rule; H3 no longer counts the slow band, whose locking is set by the imposed input envelope. Each summary.md still reports the verdict under the original rule. Model predictions were not re-run or changed.

One-line verdicts:

- H1: MISMATCH ON PHENOTYPE (RATE-BIMODAL ONLY) — model PD bimodal in 5/5 seeds (silhouette p<0.05), BIC k=2 in 5/5, but the split is PV+ (fast, regular) vs PV- (slower): model cells on the data's burst/pause centroids 0.00 ± 0.00 bursty vs data 20/45 = 0.44 (95% CI 0.31-0.59); own-cluster bursty fraction 0.73 ± 0.07; model 'bursty' cluster is PV- (Cramer's V 0.85 ± 0.13). Original rule (73 rows, no phenotype criterion): partial.
- H2 (pooled check): MISMATCH — similar distributions for 0/3 features; medians model vs rat (45 units): rate_hz 17.7 vs 29; cv 0.837 vs 1.32; burst_share 0 vs 0.0327.
- H3: UNINFORMATIVE (original rule: match; the slow-band result is set mainly by the imposed input envelope) — slow PPC match (model median 0.0862 vs rat 0.0806); beta PPC to cortical input not testable (model 0.00337 vs rat activated-epoch nan, 0 rat units qualify); beta to GPe drive not testable (model 0.00367). Secondary, slow-wave epochs: beta mismatch (model PD+SO 0.0043 vs rat all-epoch -4.62e-05).
- H4: PARTIAL — D1_ctx match, D2_ctx match, D2_gpe mismatch. Data: D2 binned 37/69 inhibited (0 excited), responders x0.56; D1 27/50 excited, x1.79.
